05 // My Journey

From learning my first lines of code to building my path toward full-stack development.

🌱 Starting From Zero

When I first entered BS Computer Science at De La Salle Lipa, I didn't know much about programming or software development. I started with curiosity, a willingness to learn, and a lot of things I had yet to discover. That curiosity became the beginning of my journey.

☕ My First Programming Language: Java

Java was the first programming language I learned. It introduced me to programming fundamentals, problem-solving, classes and objects, and the foundations of object-oriented programming. I'm still learning and improving my Java skills today, but learning it gave me the foundation to explore beyond my first language.

🧠 Building My Foundations

As I continued my Computer Science studies through Object-Oriented Programming and Data Structures and Algorithms, I started learning how to think beyond basic syntax—structuring programs, organizing data, and solving problems more effectively.

🐍 Exploring Python

My journey expanded when I started learning Python through my Introduction to Data Science course. Learning a second programming language gave me a new perspective and encouraged me to become more comfortable with unfamiliar technologies.

🎨 Understanding the User

Through Human-Computer Interaction (HCI), I discovered another side of building software: understanding the people who use it. Exploring UI/UX design and Figma taught me that good software isn't only about making something work—it's also about making it intuitive and enjoyable to use.

🌐 Stepping Into Web Development

As I became more curious about the web, I explored HTML, CSS, and JavaScript. This was where programming started to feel more tangible, seeing how code, design, and interaction come together to create an actual website or application.

🗄️ Exploring the Backend

I started looking beyond what users see on the screen. Exploring databases, APIs, and working with Supabase during a workshop gave me a glimpse into how applications connect to data and how systems behind an interface work.

🤖 Learning Beyond the Classroom

My learning doesn't stop with university subjects. Through online courses, AI workshops, and conversations with seniors, fellow students, and tech professionals, I've gained valuable industry insights and kept my curiosity alive.

🔨 Learning by Building

I'm now focusing more on building projects and applying what I learn. For me, the goal is no longer just "What do I know?" but rather "What can I build with what I know?"

🚀 Where I Am Now & Where I'm Headed

Right now, I'm developing skills across Java, Python, Web Tech, UI/UX, Databases, Git, and AI. My goal is to become a Full-Stack Developer who understands both the frontend and backend while keeping the user experience in mind. I'm not there yet—and that's okay. This is only the beginning.
